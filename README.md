# NEXT Website

Ein Mini Side Projekt, um meine Frontend Skills zu testen und zu zeigen.

## Über das Projekt

Eine moderne, responsive Landing Page für eine fiktive Tech Marke namens "NEXT". Gebaut von Grund auf mit HTML, CSS und JavaScript, ohne Frameworks.

## Verwendete Technologien

- HTML5
- CSS3 (Flexbox, Grid, Media Queries, Gradients)
- JavaScript
- Font Awesome (Icons)

## Features

- Responsive Navigation mit mobilem Menü (Hamburger Toggle)
- Hero Section mit Farbverläufen
- Sauberes, modernes Design im Dark Mode
- Für Desktop und Mobile optimiert

## Aufbau

```
Website Project/
├── images/         Bilder und SVGs
├── index.html      Startseite
├── tech.html       Tech Seite
├── styles.css      Styling
└── app.js          JavaScript
```

## Ziel

Dieses Projekt dient dazu, meine Kenntnisse in HTML, CSS und JavaScript in einem praktischen Projekt anzuwenden und weiter auszubauen.
